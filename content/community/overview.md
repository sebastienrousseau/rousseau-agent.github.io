## Overview

rousseau-agent is an independent open-source project. There is no SaaS company behind it, no support contract, no license server. The community is small on purpose — this makes it easy to know who's who.

<aside class="admonition" data-type="tip"><span class="admonition-title">Where to start</span><p>New here? Read <a href="/community/contributing/">Contributing</a>, then browse the <a href="/community/showcase/">showcase</a> for real deployments, then say hi on GitHub Discussions.</p></aside>

| Channel | Use |

## What we ship

- MIT-licensed source.
- Signed, reproducible releases with SLSA-3 provenance and CycloneDX SBOMs.
- Reference Podman Quadlet unit.
- Extensive test coverage; every commit runs against Go 1.26 on ubuntu-latest and macos-latest.

## What we don't ship

- Managed hosting.
- A support SLA.
- A "cloud" build with different features from the OSS one.

If you need any of those, run rousseau yourself — it's a single static binary.
