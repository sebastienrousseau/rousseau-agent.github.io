## Bugs and features

Open an issue at https://github.com/sebastienrousseau/rousseau-agent/issues. Include:

- `rousseau version` output.
- Go version, OS, container runtime.
- Minimal reproduction — ideally a failing test.
- Log excerpt with `ROUSSEAU_LOG_LEVEL=debug`, redacted for secrets.

## Security disclosure

**Do not** open a public issue for security-affecting reports. Email:

**sebastian.rousseau@gmail.com**

Acknowledgment SLA: 72 hours. Full disclosure SLA table lives on the [Security page](/security/).

Include a CVSS 3.1 vector if you have one, the affected component (file path and line range or dependency module), a minimal reproduction, and any coordinated-disclosure timeline you need to respect.

The full policy is in `SECURITY.md` in the source repository.

## Commercial / consulting

`rousseau-agent` is an MIT-licensed open-source project. There is no commercial support tier. Consulting engagements are ad-hoc — reach the maintainer at the email above.
