## You're offline

This documentation page is cached and readable without a network. The rest of the site will return as soon as you reconnect.

Since `rousseau-agent` is self-hosted, the daemon itself only needs network to reach its LLM provider and any active chat transport — the rest of the loop (agent, tools, session store) works fully offline.
