## Overview

<aside class="admonition" data-type="note"><span class="admonition-title">Historical snapshot</span><p>These docs describe rousseau-agent v0.5, cut before the Matrix transport shipped. For the current version, return to <a href="/">the main docs</a>.</p></aside>

## What was in v0.5

- 3 chat transports (WhatsApp, Signal, Telegram)
- 3 LLM providers (claudecli, Anthropic, OpenAI-compatible)
- No MCP server (introduced in v0.6)
- SLSA-3 provenance not yet in place
- No skills loader, no cron scheduler

## Migrating from v0.5

See [Migrations: 0.5 → 0.6](/migrations/0.5-to-0.6/). Config-file changes include the new `mcp:` block, `cron:` block, and `provider: bedrock` option. Session-store schema is forward-compatible; nothing needs to move.

## Diff to latest

- +6 transports (Matrix, Slack, Discord, iMessage, SMS, Email)
- +2 providers (Bedrock, Vertex AI)
- +MCP server (stdio)
- +Cron scheduler
- +Skills loader
- +FTS5 cross-session recall
- +Compression
- +SLSA-3 / cosign / SBOM discipline

## Full v0.5 CLI

`rousseau {chat, whatsapp, signal, telegram, session, doctor, status, version}` — same shape, minus everything MCP and cron.
