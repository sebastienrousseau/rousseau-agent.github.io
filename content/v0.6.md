## Overview

<aside class="admonition" data-type="note"><span class="admonition-title">Historical snapshot</span><p>These docs describe rousseau-agent v0.6 as tagged in Git. For the current version, return to <a href="/">the main docs</a>.</p></aside>

## What was in v0.6

- 4 chat transports (WhatsApp, Signal, Telegram, Matrix)
- 4 LLM providers (claudecli, Anthropic, Bedrock, OpenAI-compatible)
- MCP server v0.1 (initial spec revision)
- SLSA-3 provenance shipped; cosign signatures shipped
- No Vertex AI, no Slack, no Discord, no iMessage, no SMS, no email transports
- No `content/tutorials/`, no `content/recipes/`
