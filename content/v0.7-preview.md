## Overview

<aside class="admonition" data-type="warning"><span class="admonition-title">Pre-release</span><p>v0.7 is not yet tagged. This page tracks what has landed on <code>main</code> since v0.6 and will become the v0.7 archive on the tag cut.</p></aside>

## Since v0.6

- **PWA:** offline-capable via service worker at <code>/sw.js</code>, install prompt, share target
- **Provenance:** every rendered docs page fingerprinted with SHA-256, manifest at <code>/provenance.json</code>
- **Semantic search:** BM25 + stemming + synonym expansion + title bigrams; offline; 525 KB index
- **In-page AI Q&A:** <code>&lt;dialog&gt;</code>-based Ask panel, wired to the retrieval index
- **i18n:** 7 languages, hreflang alternates static-injected + runtime-injected
- **Versioning:** version selector + v0.5, v0.6 archives
- **Carbon posture:** documented page-weight budget + carbon.txt

## What's still open

- Row 3 (i18n) interior body coverage at ~27% per language — target 80%+ by v0.7 tag.
- Real recorded video walkthroughs — the CSS-animated TUI + SVG diagrams are stand-ins today.
- External semantic search (Algolia or Kapa) as an alternative to the offline BM25 index — optional.
